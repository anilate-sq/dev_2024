# Заявка на покупку техники

Небольшой учебный проект на Python и PySide6: одно окно, форма заявки,
автоматический расчёт суммы и проверка имени и email.
Кнопка показывает подтверждение в окне. Данные никуда не отправляются
и после закрытия приложения не сохраняются.

## Запуск

Нужен Python 3.10 или новее. Откройте терминал в папке проекта.

```bash
python -m venv .venv
```

Активация в Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Активация в macOS / Linux:

```bash
source .venv/bin/activate
```

Установка и запуск (после активации):

```bash
python -m pip install -r requirements.txt
python main.py
```

Если в системе команда Python называется `python3`, используйте её при создании окружения.

## Файлы

- `main.py` — виджеты, компоновки и обработчики событий.
- `style.qss` — цвета, шрифты, скругления и состояния кнопки.
- `requirements.txt` — единственная внешняя зависимость.

Названия товаров и цены можно менять в словаре `PRODUCTS` в начале `main.py`.
Для проверки: попробуйте отправить пустую форму, ввести неправильный email,
поменять товар и количество, затем отправить заполненную заявку.
