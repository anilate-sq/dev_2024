## Как устроены материалы

- `README.md` — вводная страница занятия, ссылка на презентацию либо конспект.
- `examples/` — исходный код демонстрационных примеров (если есть).
- `homework.md` — домашнее задание (если опубликовано отдельно).

**Переименовывать существующие папки и файлы не нужно:** ссылки ведут на текущую структуру, а примеры остаются на прежних местах. Если в какой-то теме нет презентации или отдельного задания, используйте материалы, опубликованные для этой пары.
