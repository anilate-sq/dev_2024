## Как пользоваться

1. Откройте нужную дисциплину по ссылке выше.
2. Выберите занятие и перейдите к его материалам.
3. Используйте презентацию, конспект и исходный код для изучения и выполнения задания.
4. Сохраните собственное решение в своём GitHub-репозитории и сдайте ссылку способом, указанным преподавателем.

Для локального просмотра файлов:

```bash
git clone --branch dev https://github.com/anilate-sq/dev_2024.git
```

## Общий формат

- **Корневой README** — навигация по дисциплинам.
- **README дисциплины** — список опубликованных занятий.
- **README занятия** — материалы занятия или ссылка на презентацию.
- **`examples/` и другие папки с кодом** — демонстрационные примеры, если они предусмотрены темой.

Существующие названия папок и файлы примеров сохранены. Структура внутри дисциплин может различаться.
